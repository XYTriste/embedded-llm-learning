# 路上一小时复习提纲（主动回忆版）

> 2026-09-23 生成 · 使用方法：每幕先**合卷默答**（心里或嘴上说出声），再对照答案；
> 卡住超过 30 秒的标记 ⭐，学习时贴给 Kimi 针对性重讲。
> 覆盖范围：量化与文件 / 网络结构 / 生成与幻觉 / 速度与工程账 / 训练，共五幕。

## 第一幕：量化与文件（10 分钟）——"模型怎么存"

**自测 1**：Q4_K_M 的 4.36 GB 里，那 0.5 字节存的到底是什么？正负号藏在哪？

> 存的是**格子序号 q∈[0,15]** 而非权重本身；正负号藏在 **min 平移量**里（INT4 全部用来编码幅度）。

**自测 2**：Q4_K 的 super-block 是几个权重？多少字节？折合成几 bit/权重？为什么需要 d/dmin 两把大尺子（想想 6bit 存 scale 的理由）？

> super-block = **256 权重 / 144 字节 / 4.5 bit**，内含 8 个子块；子块小尺子的 scale/min 各用 6bit 存储——若用 FP16 存（4 字节/32 权重）反而比 Q4_K 整体**多占一倍**，所以二次压缩成 6bit。

**自测 3**：Q4_K_M 的"M"是什么意思？全文件平均几 bit/权重？

> M = **混合精度配方**——ffn_down/输出头等约 29 个敏感 tensor 用 Q6_K（6.56bit），其余 Q4_K；全文件平均 **4.91 bit/权重**，体积账/带宽账/实测速度账三账闭环。

## 第二幕：网络结构（15 分钟）——"一句话怎么流动"

**自测 4**：在脑中走一遍完整链路，说出每个环节的形状变化（以 T 个 token 为例）：embedding → block×28 → 输出头。

> 词表查 id（152064 行表取 3584 维行向量）→ **[T,3584]** → 每 block：RMSNorm → QKV 投影（Q 28 头、KV 各 4 头，GQA）→ scores = q·k/√d 得 **[T,T]** → causal mask（−inf 而非 0）→ softmax → 加权 V → 残差 → FFN（gate/up 3584→18944，silu 门控，down 回 3584）→ 残差 → output_norm → 输出头 **[T,152064]** 只取**最后一行**。

**自测 5**：为什么注意力需要 √d 缩放？为什么 FFN 需要 silu 这种非线性（从"28 层复合=1 层"想）？18944 这个数怎么来的？

> √d 压住"维度带来的虚胖"，防 softmax 赢家通吃；无线性则多层线性复合**数学上等价于单层**，非线性是深度之源；18944 = **8/3·d**，三矩阵换选择性的参数平价设计。参数账：87% 参数在 FFN，FFN:attn ≈ 7:1。

## 第三幕：生成与幻觉（15 分钟）——"一句话怎么出来，又怎么错"

**自测 6**：温度 T 在 softmax 前对 logits 做什么操作？T→∞ 和 T→0 各是什么极限？

> **除法 z/T**。T→0 退化为 argmax（死板单一）；T 越大差距越被压缩、分布越平（多样但易跑题）。top-k/top-p 砍的是**长尾垃圾词**，治不了惯性。

**自测 7**（重头戏，默答越具体越好）：乔峰/岳老三系列实验得出的"骨架+槽位"模型是什么？为什么三次乔峰实验三个不同错答案是"知识缺失的呈堂证供"？

> 知识以**关系骨架 + 可填充槽位**压缩存储，槽位靠**共现邻近性**填充——模型记住"谁和谁常一起出现"而非"谁是谁"。低频实体连碎片都不剩。答案发散 = 每次从坏分布独立抽样；**知识若存在，答案应收敛**。

**自测 8**：r1 的独白和 qwen 被诱导的独白，本质差异是什么？"你确定吗"之后两个模型各是什么反应，共同证明了什么？

> 独白功能来自 **RL 训练**而非措辞——r1 会犹豫（显式化不确定性）但**无消除机制**（无锚可查证 → 振荡复读 2756 tok）；qwen 零犹豫、"确实，我需要再次确认"后原样复述（假校验最纯粹形态）。追问后 r1 漂移、qwen 不动摇——**两个模型都没有校验回路，区别只在溺水姿势**；真订正 = 改对，三轮零次。

## 第四幕：速度与工程账（10 分钟）——"数都要会算"

**自测 9**：默算——4080 上 Q4_K_M（4.68GB）vs fp16（15.23GB），实测 110 vs 19.61 t/s，带宽利用率各多少？为什么 fp16 慢于字节比？

> 110×4.68 ≈ 515 GB/s（**72%**）；19.61×15.23 ≈ 299 GB/s（**42%**）。朴素带宽模型缺**内核效率系数**——llama.cpp 优化重心在量化内核。修正预测 34×(42/72)≈19.8≈实测，闭环。工程结论：端侧全量化吃**省显存 + 内核**双重红利。

**自测 10**：首问 9 秒慢、第二问快，两个原因分别是什么？"eval rate 与上下文长短无关"的微观解释？

> 首问 = **懒加载**（load 2.57s，ollama run 不预载权重）+ **GPU 预热**（CUDA 上下文/内核/显存池）；之后 load≈2ms 模型常驻。每生成一个 token 都要**全量读一遍权重**，KV cache 只省旧 token 的重算、不省读权重——所以每 token 耗时恒定，eval rate 稳定。

## 第五幕：训练（10 分钟）——"模型怎么学"

**自测 11**：损失和梯度的区别（用海拔/坡度的比喻）？更新公式那行？反向传播的机制？

> 损失 = **海拔**（错多离谱），梯度 = **坡度**（每个参数的方向+陡度，指向损失增大方向故取反）；`w ← w − η·∇L`，一次前向+反向只更新一次，训练 = 该式 × 几万亿次；机制 = **链式法则**（上游误差×本地导数），终点不止 embedding（输出头 → blk28 → … → blk1 → embedding 行，**第一站**非终点）。彩蛋：softmax+交叉熵下 ∂L/∂logits = **p−y**——"错得越狠调得越狠"是数学必然。
