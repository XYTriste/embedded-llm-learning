## 五、已建立的核心认知（截至 2026-09-22）

1. **量化-质量权衡的第一手直觉**：Q4 文件约为 FP16 的 1/4，同机速度差距远小于跨机差距；7B 规模下 Q4/Q8 大多数问题质量几乎无差别。
2. **幻觉的机制**：目标函数里没有"真"（交叉熵奖励流利而非真实）；知识是分布式有损压缩，低频事实被平滑成"最像答案的答案"；校准断裂（token 概率≠为真概率）；RLHF 惩罚"我不知道"导致不许沉默；自回归惯性——错误一旦写下就被自己的输出锁死。
3. **知识与能力的区分**：知识（玄苦是乔峰师父）是离散的、注入"这一个事实"不泛化；能力（理解"师父"关系结构）需要关系类型的多样性。窄样本重复灌→高先验主题→过拟合行为层表现。
4. **模型三层存储 ↔ 人类记忆三层**：权重=程序性/语义记忆；上下文窗口=情景记忆（读完即弃）；RAG=外部记忆。权重=零延迟只读缓存，外挂=可读写无限容量磁盘。
5. **记忆化（memorization）**：梯度正比于损失→离群/重复样本被逐字刻进权重（同构闪光灯记忆）。推论：模型记噪声比记规律牢；刻意遗忘很难（连坐周边知识）→ RAG 外挂知识"想删就删"的不可比拟优势。
6. **自我纠正不是参数量问题而是训练范式问题**：Instruct 模型无"思考动作"故无纠错机会；推理模型（R1 类）经 RL 学会把校验独白写进 token 流。但纠偏只在**内部可验证**问题上有效，事实性记忆问题"用缺失的知识校验缺失的知识"闭环不成立。
7. **幻觉解决路线取舍**（RAG/微调/知识编辑/降温度/推理时计算/工具调用/拒答训练）：本质是补"外部锚点"或"观察者"，区别在锚点放哪、何时接入、什么代价。端侧场景组合拳退化为精简版——可切入的具体研究问题（如端侧 RAG 检索质量与幻觉率的实测权衡）。
8. **懒加载与首问延迟**：`ollama run` 启动时不加载权重，首问触发读取（load duration 2.57s）+ GPU 一次性预热（CUDA 上下文/内核加载/显存池建立，故首问 prompt eval 仅 16.74 t/s）；会话内模型常驻（之后 load duration ~2ms），新题快不是因为"缓存了上一题"而是模型常驻+GPU 已热；KV cache 只复用共享前缀（模板/上文）。会话结束后模型默认在显存保留 5 分钟（`OLLAMA_KEEP_ALIVE`）——做对比实验需控制该变量。同机补测结论：Q4 稳态 ~110-115 t/s vs Q8 ~70 t/s ≈ **1.6×**（与 i3 上比例一致），跨机 15× 主要来自 GPU vs CPU，得到验证。
9. **GGUF 容器与 k-quants 分组量化**（详见 [GGUF 与 Q4_K_M 量化原理讲义](学习内容/GGUF与Q4_K_M量化原理_讲义_20260920.md)，已对真实文件解剖验证）：模型文件=数字表格+说明书（头部+元数据仅占 0.13%）；量化=整数格子序号 q∈[0,15] + 分组小尺子（scale/min），正负号藏在 min 平移量里；Q4_K 以 256 权重为 super-block（144 B = 4.5 bit/权重），8 子块小尺子（6bit）再由 d/dmin 两把大尺子二次缩放；file_type=15 即 Q4_K_M，M=混合精度配方（ffn_down/输出头等 29 个敏感 tensor 用 Q6_K 6.56bit）；全文件平均 4.91 bit/权重，体积账、带宽账、实测速度账三者闭环。
10. **带宽预测模型的第一次修正（fp16 验证结案，9-22 晚）**：同机三档稳态解码速度 Q4_K_M≈110 t/s、Q8_0≈70 t/s、FP16=19.61 t/s。fp16 比 Q4 慢 5.6×，远大于字节比 3.1×→朴素带宽模型（字节小→快）必须乘**内核效率系数**：实测带宽利用率 Q4_K≈72%（110×4.68GB≈515GB/s vs 4080 峰值 716.8）、FP16≈42%（19.61×15.23GB≈299GB/s）——llama.cpp 的优化重心历来在量化内核，fp16 路径没有同等的调优。修正预测 34×(42/72)≈19.8≈实测 19.61，闭环成立。工程结论：端侧 4080 上 fp16 全面不如 Q4_K_M（慢 5.6×、质量差异不可感知、乔峰题已证错误与量化无关）。**测量教训：GPU 性能测量必须以交互会话手动运行为准**——我的后台自动化同命令只测得 4.68/0.42 t/s（与手动差 4~40 倍），`ollama ps` 证明模型 100% GPU 驻留（14GB、CONTEXT 4096）排除卸载，后台会话 nvidia-smi NVML 初始化失败为同因旁证；最大嫌疑是非交互后台会话的 GPU 时钟/调度受限，其次是测量时用户可能正在用机（GPU 争抢），如实标注不确定。
11. **从 logits 到自回归生成闭环（9-22 晚，推理链路收官课）**：输出头 logits=逐 token 打分（152064 维对应词表，与 embedding 共表=查表/打分同一几何动作正反两面）；softmax=e^z 压正+归一化，排序不变但差距放大；生成靠按分布抽样而非 argmax（否则输出单一死板的多样性来源）；温度=softmax 前 z/T 除法放缩，高温压缩分数差距→分布平坦→多样（防高分词一家独大的机制是"削弱领先优势"非"放大"）；top-k/top-p 砍长尾垃圾词（效率+防离谱词），非治惯性；自回归=新 token 拼回上下文再全量前向，惯性=错误固化为下一轮前提→**错误级联（自信地错，非越来越随机）**，低温度只能缓解，根治靠外部锚点。回收伏笔：幻觉=从概率分布抽样+平摊到 15 万词上"长得像答案"高分即翻车；decode 只取 scores 末行；KV cache 免重算旧 K/V 但每轮仍全量读权重→eval rate 稳定即带宽账微观基础。**至此"一句话进、一句话出"全链路（①BPE→②embedding→③28×block→④输出头→⑤softmax+采样→⑥自回归循环）全线闭环，网络结构+推理课完结**。
12. **知识以"骨架+槽位"压缩存储（岳老三实验，9-22 晚，"碎片缝错位置"假说的精确化）**：三次提问（裸问→点明书名+/clear→用户纠正）分别演示张冠李戴（低频名缝到高频实体，频率即先验）、稳定缺失（/clear 后仍否认→排除上下文污染；跨书"岳姓"碎片串味）、谄媚+编造补全+错误级联（"你说得对"→捏造"岳腐"、名单混入鸠摩智/殷野王，但"段延庆排第一"对）。核心图景：骨架（天龙八部有四大恶人组织）全对、槽位（其余三人）拿共现邻近的高频恶人凑数——**模型记住"谁和谁常一起出现"，不是"谁是谁"**；低频实体在分布式压缩中连碎片都不剩；**用户纠正注入的是槽位而非知识，不触发校验**（呼应认知 6）。乔峰题同修：玄苦对=共现高频，慧光/丁春秋=邻近填充。
13. **推理模型翻车四形态（deepseek-r1:7b 对比实验，9-22 晚，认知 6 的补证与升级）**：独白把**不确定性显式化**（犹豫信号"可能/不太确定/我可能记错了"十几次，qwen2.5 是零犹豫直编）但没有**消除机制**——确定性只能由计算制造（内部可验证题：水池题五步程序推理全对，441 tok）或本来就记得（事实题）；缺失时思考流退化为**振荡吸引子**（自回归惯性放大版：循环引用自我加固，五步小循环原样复读 ~20 遍、2756 tok/32s 无信息增益，"龙 snail"=低概率 token 残片被循环滚大）；用户质疑→**随机漂移**（乔元杰+张天师→改龙 snail+张天师，两次答案互斥→独白无校验回路实锤，"再想想"无锚时=从同一坏分布重抽样）；编造名全为真实历史名人填槽（张择端/周敦颐/张天师）+真实骨架缺失（不知汪剑通/玄苦，比 qwen2.5 碎得更彻底，同构认知 12）。**思考 token 只在内部可验证问题上赚回票价，事实问题上是负资产**。技术账：r1:7b Q4 85~88 t/s 符合带宽模型。原始输出存档 [实验记录_deepseek-r1对比_20260922](学习内容/实验记录_deepseek-r1对比_20260922.txt)。
