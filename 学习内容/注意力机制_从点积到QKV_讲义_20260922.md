## 第 0 站 · 复习：词表 → embedding 的正确图景

**原理解述**（2026-09-22 复习验收，主干全对，三处机制精修）：

1. **词表何时冻结**：词表是 **tokenizer 训练（BPE）的产物，在大模型训练开始之前就已建好并冻结**。模型训练全程不改词表（embedding 行数 = 词表大小，结构先定才能初始化）。准确时序：BPE 离线跑完 → 词表冻结 → 大模型训练只学这张表里的行向量内容。
2. **BPE 合并机制**：从最小单元（字符/字节）出发**反复**迭代：①统计当前语料所有相邻 pair 的频率；②合并频率最高的 pair 成新 token 加入词表。循环直至目标大小（Qwen2.5 为 152064）。词表里每个 token 都是"某对邻接片段曾频繁共现"的化石。
3. **embedding 层没有计算**：前向 = 一次查表（token id = 行号，地址跳 `id × 3584 × 2` 字节，见 shape-conventions 约定 1）。它之所以能学习，是因为查表可微：反向传播把上游梯度**路由**到被抽中的行，其余行梯度恰为 0——不是"计算图里没有别的行"，而是"别的行这一步梯度为零"。一个 batch 里没出现的 token，其行向量这一步纹丝不动。

## 第 1 站 · q/k/v 是什么：一个向量要同时打三份工

**设问**：一个 token 只有一个向量（3584 维），注意力却要求它同时干三件不同的事，怎么办？

**图书馆比喻**：

- **Query = "我想找什么"**——你手里写的检索词；
- **Key = "我是什么"**——每本书书脊上的分类标签，供所有人比对；
- **Value = "我被选中后贡献什么"**——书的正文，真被借走才打开。

**机制**：把同一个 x（3584 维）分别乘三个学出来的矩阵：

$$q = xW_q, \quad k = xW_k, \quad v = xW_v$$

同一个 x，三份不同的"问法 / 标签 / 内容"。W_q、W_k、W_v 与 embedding 表一样，都是反向传播学出来的参数。

**一个 token 的 q 与另一个 token 的 k 做点积，得到的就是"我对你有多感兴趣"——这是 scores 矩阵里一个元素的全部含义。**

## 第 2 站 · scores 的来历：一个元素到 [T,T]

**最小例子**：2 个 token，单头、头维 d = 2（先不管多头，当只有一根注意力通道）。

- token 1：$q_1 = [1, 0]$，$k_1 = [1, 0]$，$v_1 = [1, 2]$
- token 2：$q_2 = [1, 1]$，$k_2 = [0, 1]$，$v_2 = [3, 4]$

scores 的元素 $(i, j)$ 就一句话：**token $i$ 的 q · token $j$ 的 k，除以 $\sqrt{d}$**：

$$\text{scores}[i,j] = \frac{q_i \cdot k_j}{\sqrt{d}}$$

**[T,T] 的来历**：两个 token 两两配对，$i$ 有 2 种取法、$j$ 有 2 种取法，自然铺成 $2 \times 2$。它不是形状约定，而是"每个 token 都要对包括自己在内的每个 token 问一遍"的必然结果——T 个 token 就是 T×T 个"问答对"。

**动手算一个元素**，$\text{scores}[2,1]$（token 2 对 token 1 的兴趣）：

$$\text{scores}[2,1] = \frac{q_2 \cdot k_1}{\sqrt{2}} = \frac{[1,1]\cdot[1,0]}{1.414} = \frac{1 \times 1 + 1 \times 0}{1.414} \approx 0.707$$

点积 = 逐元素相乘再求和；维度相同才能点积，这正是 q 与 k 必须等长的原因。

**除以 $\sqrt{d}$ 为什么**：点积是 d 个数相加，d 越大数值天然越大（d=128 时随便点点积就十几）。不除，softmax 会被少数巨型数值压成"赢家通吃"，梯度消失。除以 $\sqrt{d}$ 是把"维度带来的虚胖"压回去，让数值尺度与 d 无关。

## 第 3 站 · 核心之问：点积凭什么能表示"标签 / 想找什么"？

**一句话答案：点积本身不携带任何语义，它只是"方向相似度"的计算器；语义是训练用梯度一刀一刀雕刻出来的。**

### 3.1 几何层：点积到底算了什么

$$q \cdot k = |q|\,|k|\,\cos\theta$$

方向越一致点积越大，垂直为零，反向为负——就只干了这一件事。

**退化情形看清本质**：若 $k = [1, 0]$，则 $q \cdot k$ 就是**直接读出 q 的第 0 个坐标**——字面意义的"查标签"：坐标是 0.9 还是 0.1，回答"是不是第 0 类"。

**一般情形靠高维叠加**：单个坐标可承载一个微观语义特征（"是不是名词""是不是宾语位置""是否指代前文某物"……成千上万个软特征叠加在同一段向量里），于是

$$q \cdot k = \sum_{m} q_m k_m = \text{成千上万个微观特征匹配的加权和}$$

点积一次性评估所有维度上的吻合度，压成一个数。"标签"不是符号，是**分布在坐标里的、可被点积整体读出的模式**。

**等价视角**（值得记住）：代入 $q = x_i W_q$、$k = x_j W_k$，

$$q_i \cdot k_j = x_i^{\top} \underbrace{(W_q W_k^{\top})}_{\text{学出来的矩阵}} x_j$$

注意力分数本质是**一个由训练决定的 token 对二次相似度函数**。用不用点积形式都行——点积只是最省参数（两个矩阵）且与 GPU 矩阵乘天然匹配的表达。

### 3.2 训练层：语义是怎么被雕进去的

初始时 q·k 确实什么也不表示（随机 $W_q, W_k$ 无结构）。雕刻分三步：

**① 压力来源**：训练目标是预测下一个 token。若 token $j$ 的 $v$ 含有"预测 token $i$ 之后所需的信息"，增大 $\alpha_{ij}$（i 对 j 的注意力权重）就降 loss。每个样本都在对所有 token 对打分："你对我有没有用。"

**② 梯度的具体方向**：softmax + 交叉熵的梯度有漂亮形式

$$\frac{\partial L}{\partial s_j} = \alpha_j - y_j$$

链式传回 q（$\partial s_j / \partial q = k_j / \sqrt{d}$）：

$$\text{更新} \; q \leftarrow q - \eta \sum_j (\alpha_j - y_j)\frac{k_j}{\sqrt{d}}$$

翻译：**q 朝"有用的 k"走一小步，同时背离"没用的 k"**。几何上就是让 $\cos\theta$ 变大——这就是训练雕刻点积含义的全部机制。

**③ 玩具实证**（[why-dot-product-works.py](../why-dot-product-works.py)，可复跑）：$k_1=[1,0]$、$k_2=[0,1]$，token 2 有用，q 从随机方向手工梯度下降：

| step | $s_2 - s_1$（兴趣差） | $\alpha_2$（给 token2 的权重） |
|---|---|---|
| 0 | 0.28 | 0.57 |
| 3 | 0.85 | 0.70 |
| 5 | 1.14 | 0.76 |

兴趣差单调拉大，注意力持续向有用 token 集中。

**规模化**：真实训练更新的不是 q 而是 $W_q$（$q = xW_q$），且 x 的表示层同时被训练——表示（x）、匹配（W_q/W_k）、内容（W_v）三层协同雕刻。数十亿 token × 28 层 × 28 头 × 数十万步后，每个头长出可辨认分工：句法依存头（动词找主语/宾语）、指代回溯头（it 找前文名词）、位置头……**"q 想找什么、k 是什么标签"不是人指定的，是自组织涌现、事后可解释的**。

### 3.3 V 为什么单独存在

"对谁感兴趣"（路由）与"交出什么信息"（内容）是两个独立目标，耦合在一个矩阵里会互相拖累（一个 token 可能"很想被注意"但内容无用，或"内容关键"但不该对每个邻居广播）。拆开后：$W_q, W_k$ 专心学匹配准则，$W_v$ 专心学"我携带什么对别人有用的信息"。

### 收束

数学上 Q、K、V 确实只是点积与矩阵乘；"标签/想找什么/贡献什么"不在运算里，而在 loss 雕刻出的矩阵方向里。运算只是"相似度计算器 + 内容搬运通道"，语义是数十亿次"有用就靠近、没用就远离"的梯度更新的沉淀。图书馆比喻是训练完成后起的名字——贴切，但它是结果不是前提。
